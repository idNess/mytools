A Redmap type counts as API v3 in pre-prod when the API v3 column says v3 (the v3 APIs run in DV and pre-production only, and the production release is planned for the end of Q4 2026; the API v2 column marks types served by the v2 API), as in build when it says Next, and as ETL shapes defined when it has no API but has a root or SHACL shape, which means its ETL workflow is under development. The workflow figures count types with a BPMN workflow listed in the Workflows PROD or Workflows DV column. The 16 press types struck through in the Redmap file are ignored, and the 16 Register press types that map only to them count as having no Redmap equivalent. The Rules of Procedure types count with the v3 APIs because the file lists them on v3 and no longer carries a DEVELOP status. Three discontinued types are fed by a one-shot Redmap load. Eight committee shapes are marked "proposed" and count as shapes defined. Register types are linked to Redmap types as in the Register mapping file, which now lists only the 111 Redmap types; Register types without one are counted as having no Redmap equivalent.
